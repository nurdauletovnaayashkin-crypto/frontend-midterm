# Wanderlens - Coastal Pass Web Application

## Project Overview
Wanderlens is an all-inclusive web platform designed for travelers who love coastal escapes and island adventures. The platform allows users to explore pristine coastal views, verified maritime tours, scenic towns, and top-tier attractions with a single unified coastal pass.

## Development Time & Effort
This project was successfully designed, structured, and implemented by our team in exactly 9 hours of continuous teamwork, dedication, and coding.

## Project Goals & Objectives
* Unified Access: To create a centralized digital pass solution for booking and exploring coastal destinations seamlessly.
* User-Centric UI/UX: To deliver an aesthetically pleasing, elegant interface utilizing modern typography and calm coastal color palettes.
* Comprehensive Navigation: To provide multi-page browsing including Home, Discover, Attractions, Experiences, Trip Planning, About, and Contact sections.
* Full Responsiveness: To ensure absolute adaptability across laptops, tablets, and smartphones.

## Technologies Used
* HTML5: Semantic page structure and layout markup.
* CSS3: Custom styling, CSS variables, and layout rules.
* Tailwind CSS: Utility-first framework for rapid and modern UI component styling.
* Font Awesome: Professional icons for navigation and features.
* Google Fonts: Playfair Display (serif) and Plus Jakarta Sans (sans-serif) typography.

## Responsive Design
The application is fully optimized for all modern screen sizes:
* Laptops & Desktops: Expanded multi-column layouts, rich hero sections, and persistent navigation bars.
* Tablets: Balanced scaling and touch-friendly interactive elements.
* Smartphones: Adaptive typography, flexible grids, and mobile-friendly layouts.

## How to Run the Project
1. Clone or download this repository to your local machine.
2. Open the project folder in Visual Studio Code.
3. Open index.html in any modern web browser or run it using the Live Server extension.
